Wireframes

Low-fidelity layouts for every screen of the Virtual Tour & Cultural Mapping app — structure and hierarchy, one screen per page.
Version 1.1.1 · Portrait phone, 360 dp wide reference
Design artefacts — not screenshots

Wireframe key

How to read these low-fidelity wireframes: layout and hierarchy only — no colour, imagery or final copy. Numbers refer to the notes beside each screen.

  1. Image or photograph (crossed box).
  2. Heading and body text (grey bars stand for paragraphs).
  3. Primary (solid) and secondary (outline) buttons.
  4. Chips: filled = selected.
  5. Input field.
  6. List card with photo, favourite heart and category tag.
  7. Dashed outline = element shown only in some states.
  8. Bottom tab bar: Home · Explore · Map · Progress (filled = current).

Onboarding

A three-slide introduction shown only on first launch.

  1. Skip — always available; leaves the introduction.
  2. Large illustration for the slide.
  3. Title and short supporting text (3 slides: tours, learn & quiz, journey).
  4. Page dots (“1 of 3” for screen readers).
  5. Next → Get started on the last slide.

Welcome (and auth entry)

First screen when there is no session and no guest choice; Sign In and Sign Up are one step away.

  1. App emblem, name and tagline.
  2. Create an account (sign-up form: email, password, confirm).
  3. Sign in (email, password; friendly error messages).
  4. Continue as guest — every feature, progress kept on the device.

Sign in / Sign up

A single-column form with validation and friendly errors.

  1. Back to Welcome.
  2. Email and password fields with validation on submit.
  3. Plain-language error (wrong password, rate limit…).
  4. Primary action; Sign Up mirrors this layout.

Home

Entry point: search, featured destinations and shortcuts.

  1. Settings (gear).
  2. Search — submitting opens Explore with the query.
  3. Featured carousel (varied, rotates daily) → Details.
  4. Shortcuts to the planner and Insights.
  5. Category grid and province shortcuts → pre-filtered Explore.

Explore

Searchable, filterable list of all destinations.

  1. Search-as-you-type.
  2. Category and province chips (single-select, combinable).
  3. Near me prompt (optional) and Nearest first sort.
  4. Destination card → Details; heart toggles favourite; ★ rating when rated; distance when location is on.
  5. Add destination (floating action button).

Destination details

Everything about one place, with the main actions pinned at the bottom.

  1. Back · share · favourite.
  2. Name, category and province tags; Visited / best-score badges when earned.
  3. Directions (Google Maps) and 360° Street View.
  4. Star rating card with average and count.
  5. Long-form sections appear only when they have content.
  6. Primary tour action and Quiz (shows the best score).

Add / Edit destination

One shared validated form for creating and editing.

  1. Cancel.
  2. Photo picker → resized to ≤1600 px → uploaded with staged progress.
  3. Required: name, description, address, province, category.
  4. Optional coordinates (numeric).
  5. Save; also generates the starter quiz for a new entry. Edit uses the same form.

Virtual tour — Gallery (and Intro)

The Intro step shows the cover, name and description; the Gallery step lets the visitor browse credited photos. Dark “gallery wall” styling in high fidelity.

  1. Close the tour; step indicator.
  2. Swipeable photo, credit shown for every photo.
  3. Page dots.
  4. 360° card (hidden offline).
  5. Previous / next step arrows.

Virtual tour — 360° View

Run 8: an in-app Street View step between the Gallery and Chapter I, only for places with a panorama.

  1. Step indicator: the 360° View is step 3 (Intro, Gallery, 360°, Chapter I, Chapter II, Complete). Places without a panorama keep 5 steps.
  2. Exhibit-wall heading; “View in 360°” on Details opens the tour right here.
  3. Full-bleed panorama from the Maps Embed API in a WebView; a pulsing shimmer until it has loaded.
  4. Localized hint to drag (and pinch) inside the view.
  5. Google credit and the way out to Google Maps.
  6. Gentle note for places added in the app where Google may have no imagery. The step is hidden offline.

Virtual tour — Chapter

History and Cultural Significance chapters with optional narration.

  1. Chapter label and title (Chapter II: Cultural Significance has the same layout).
  2. Lead sentence set apart by a gold rule.
  3. Listen — reads the chapter aloud; pulses while playing; hidden with no English voice.
  4. Body text on cream paper; scrolls.

Virtual tour — Completion

The final step records the visit and offers the quiz or a real visit.

  1. Completion message.
  2. Mark as Visited (saved once per user; success haptic).
  3. Continue to the quiz.
  4. Hand-off to the real world: directions and Street View.

Quiz — question

One question at a time with instant feedback; the intro card and the score screen (ring, X/5, Retake / Back) share this frame.

  1. Progress bar and counter.
  2. Question text.
  3. Four shuffled option cards; correct/wrong shown with icon + colour (never colour alone).
  4. Next / See my score.

Quiz — result

Score summary; the attempt is saved and the best score derived.

  1. Score ring with X/5 and percentage.
  2. Encouraging or celebratory message.
  3. Retake (options reshuffle) or return.

Progress

Personal dashboard: identity, completion, statistics, favourites and journey.

  1. Settings and Heritage Insights.
  2. Identity card: account or guest, with sign-out / upgrade nudge.
  3. Visited ring (N/26) and quiz statistics.
  4. Per-province completion bars.
  5. Badges screen; certificate when a province or the region is complete.
  6. Favorites list.
  7. Journey list (visited + best score) or friendly empty state.

Badges

Ten achievements derived from visits, quizzes and favourites.

  1. Summary count.
  2. Earned badge: full emphasis and date.
  3. Locked badge: dashed outline, lock and a progress meter (“Locked · n of m”).

Certificate of Completion

Awarded per province or for the whole region and shared as an image.

  1. Printed-document design: parchment, frame, laurels (same in light and dark).
  2. Holder name, achievement and date.
  3. Editable name (remembered).
  4. Share as an image through the system share sheet.

Heritage Insights

Aggregate statistics across all users, with empty states and offline copy.

  1. Community totals: visits, quizzes, ratings.
  2. Most visited, top rated and toughest quiz rankings.
  3. Meter rows by province and category (no chart library).

Field trip planner — select

Choose up to eight destinations.

  1. Search the checklist.
  2. Selection counter with the 8-stop limit.
  3. Checkbox rows; the selection order is numbered.
  4. Optional start from the current location.

Field trip planner — route

Run 8: the route follows real roads (OSRM) with real driving distance and time; a straight dashed line is the fallback.

  1. Route map: the road-following line and numbered pins. A small chip shows while the road route is being found.
  2. “Road route” badge (or “Straight-line route — approximate”) and the OSRM / OpenStreetMap attribution.
  3. Reorder (up / down) or remove; each leg shows its road distance and time. Reordering asks for a new route (debounced).
  4. Total road distance and driving time.
  5. Fallback when offline or the routing server fails: straight dashed segments, “approximate” figures and a short note — never an error.
  6. Save keeps the route with the plan on the phone, so a saved plan reopens with its road line, also offline.

Map

All destinations on Google Maps (a schematic map in the web demo).

  1. Legend chips double as category filters.
  2. Show the whole region.
  3. Category-coloured custom pins; the selected one grows.
  4. Preview card with the route to Details.

Settings

All preferences in one place, saved on the device.

  1. Appearance: System / Light / Dark, instant.
  2. Language: English / Filipino, instant, no restart.
  3. Narration options.
  4. About: version and repository link; web-only demo notice.
  5. Photo credits and open-source note.

Photo credits

Licence attribution for every photograph.

  1. Framing sentence about Wikimedia Commons.
  2. All 78 credit lines grouped by destination, read live from the database.
